# Project Kit — decyzje

Tryb: Operate. Odbiorca buduje brief dla człowieka lub agenta. Jedna przestrzeń edycji, porównanie oparte na lokalnych stylach i jawny eksport. Właściciel kierunku: impeccable; dziedziczymy DESIGN.md: jasne neutralne powierzchnie, systemowe UI, oszczędny indigo i czytelne kontrolki. Research ui-ux-pro-max zasugerował przesadny minimalizm i pomarańczowe CTA; odrzucono je jako sprzeczne z istniejącą biblioteką. Dane podglądów są ilustracyjne, bez deklaracji wyników. Podgląd ładuje tylko wykorzystywane rodziny przez Google Fonts (display=swap); status pokazuje faktyczne załadowanie albo fallback. Dostawca fontów otrzymuje zapytanie przeglądarki; ZIP nie zawiera fontów. Licencje należy zweryfikować u źródła.

Zapis lokalny: `aie-design-kit-v1`. Identyfikatory assetów: klucze kolekcji z assets.json, ikony `lib:name`, inne `key || id || name`; komponenty `components:button` i `components:input` to autorskie, deterministyczne przykłady. ZIP zawiera manifest JSON, brief, tokeny CSS i dostępne pliki/definicje assetów; źródła i licencje w briefie.

Eksport kończy się błędem, jeśli identyfikator lub zasób jest nieznany, ikona niedostępna lub wartość CSS nie jest samodzielna i obsługiwana. Nie powstaje częściowy ZIP. Pozostałe podglądy korzystają z oryginalnych kolorów i fontów stylu, wybrany — z edytowanego zestawu.
